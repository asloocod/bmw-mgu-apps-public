# vr-hud-turn: поворотники на HUD

Включён поворотник, и на проекционном дисплее у левого или правого края мигает зелёная стрелка. При аварийке мигают обе.
Стрелки горят и тогда, когда машина мигает сама: ассистент смены полосы мигает в сторону, после экстренного торможения,
при угрозе наезда сзади или аварии включается аварийка.
Сервис без экрана в iDrive. Он стартует вместе с головным устройством (MGU, iDrive 7) и рисует через
[Cluster renderer](https://github.com/robertnisipeanu/idrive-apps/tree/main/native/cluster-render) (`cluster-render`),
Store ставит его первым. Машину сервис только читает: подписки SOME/IP, ничего не пишет.
Область HUD сервис занимает только во время поворота, остальное время она свободна.
В Sport и Sport+ HUD показывает слева тахометр, поэтому в этих режимах стрелки встают на свою высоту `y_sport`.
Режим сервис узнаёт от машины и переставляет стрелки сразу, даже посреди поворота.

## Приложение «Поворотники на HUD»

Ставится из Store отдельно (`vr_hud_turn`), в iDrive лежит в «Приложениях». Сервис работает и без него.

| Настройка | Шаг | Что делает |
|---|---|---|
| Выше / ниже, px | 10, от −120 до +120 | плюс поднимает стрелки, минус опускает |
| Выше / ниже в Sport, px | 10, от −120 до +120 | то же для Sport и Sport+ |
| Шире / уже, px | 10, от −80 до +80 | плюс разводит стрелки к краям, минус сводит к центру |
| Размер, % | 10, от 70 до 160 | размер стрелок |
| Цвет | | зелёный (как сейчас), белый, жёлтый, оранжевый, голубой |
| Яркость, % | 10, от 30 до 100 | ночью зелёный на 100 % может слепить |

Ноль (у размера и яркости 100, цвет зелёный) оставляет стрелки такими, как по умолчанию. После каждой правки обе стрелки горят 15 секунд,
так новое место видно сразу. Правка высоты для Sport показывает стрелки на высоте Sport в любом режиме.
Кнопка «Показать стрелки» делает то же самое, «Сбросить» возвращает все настройки к умолчанию.
Стрелки для подгонки загораются только на стоянке (до 5 км/ч). На ходу правка сохраняется, но стрелки не загораются.
Включённый поворотник прерывает показ.

## Лог для разбора

Если стрелки ведут себя странно, лог можно записать и передать без компьютера.

1. В приложении нажмите «Начать запись лога» и поездите, включая поворотники так, чтобы ошибка повторилась.
   В запись попадает каждое событие поворотника от машины, режим, скорость и всё, что пишет сервис.
2. Нажмите «Остановить запись лога». Запись остановится и сама, через 30 минут или на 2 МБ.
3. Включите точку доступа машины и подключите к ней телефон. Нажмите «Отдать лог на телефон».
   На экране появится адрес вида `http://172.16.222.97:8471/…`, он работает 10 минут.
4. Откройте адрес в браузере телефона, нажмите «Скачать лог» и отправьте файл в Telegram.

В файл входят запись и `events.log`. Адрес содержит случайный код, поэтому другой телефон в той же сети его не угадает.
На время показа сервис открывает порт 8471 на точке доступа так же, как Store открывает свою страницу на 8470, потом закрывает.
Запись хранится в `/var/opt/vr-hud-turn/log/record.log`.

Приложение хранит настройки у себя (`/var/opt/public/oap/oap_<uid>/data/settings.json`), сервис читает их при старте
и при каждой правке. Связь идёт через сокет `/run/vr-hud-turn/ctl.sock`, доступный только группе приложения.
Если приложение поставлено позже сервиса, сервис находит его в течение минуты.

## Настройки

Файл `/var/opt/vr-hud-turn/config.json` переживает обновления. Читается при старте, после правки нужен
`systemctl restart vr-hud-turn`. Неверное значение игнорируется, остаётся умолчание.

| Ключ | Умолчание | Диапазон | Что это |
|---|---|---|---|
| `period_ms` | 640 | 300–1500 | полный цикл вспышки, мс (замер на X6 G06) |
| `duty` | 0.5 | 0.2–0.8 | доля цикла, когда стрелка горит |
| `phase` | `"light2"` | `"light2"`, `"timer"` | `light2`: каждая вспышка привязывается к событию машины `StatusFunctionsIndicators2`. `timer`: только таймер |
| `stale_ms` | 1500 | 0 или 700–10000 | во время поворота нет событий столько мс: стрелки гаснут (0: не гасить) |
| `size` | 40 | 20–400 | высота стрелки, px холста 800×480 |
| `margin` | 190 | 0–300 | от края холста до острия, px (HUD показывает меньше холста: при 100 острие уже обрезано, при 150 правую стрелку не видно, когда голова повёрнута к правому зеркалу) |
| `y` | 240 | 0–480 | центр стрелок по высоте, px (0 вверху холста) |
| `y_sport` | 240 | 0–480 | то же в Sport и Sport+ |
| `show_ms` | 15000 | 1000–60000 | сколько горят стрелки по кнопке приложения, мс |
| `show_max_kmh` | 5 | 0–50 | выше этой скорости стрелки по кнопке не загораются |
| `color` | `[0, 0.85, 0.3]` | 0–1 | цвет RGB, он же «Зелёный» в приложении |
| `test_pattern` | `false` | | `true`: обе стрелки горят всё время, для подгонки положения |

Пример:
```json
{ "test_pattern": true, "margin": 170, "y": 260 }
```

Сдвиги из приложения прибавляются к этим значениям.

## Журнал

```sh
journalctl -u vr-hud-turn -f
```
Пишутся смены направления (`direction left at <мс>`), сырые значения полей `Light` при каждом изменении,
выключение по таймауту (`stale`) и при пропаже поставщика сигнала, сырые значения режима (`FES.statusFESVehicleDynamicSwitchHMI`),
положение стрелок (`place y … margin … size …`), настройки приложения и его команды (`app: show -> ok sport`),
состояния цели HUD у cluster-render,
обрыв связи с ним и ошибки запуска (сервис сам повторяет запуск раз в 60 с).

Журнал на машине хранится всего несколько минут, поэтому те же строки пишутся в `/var/opt/vr-hud-turn/log/events.log`
(до 256 КБ, плюс предыдущий `events.log.1`). По нему после поездки видно, что машина присылала, например при смене полосы ассистентом.

## Скорость на HUD

Стрелки рисуются в той области HUD, где приборка показывает плеер, списки и карту (слот `0x323`, другой области
у cluster-render на iDrive 7 нет). Пока область занята, приборка отодвигает скорость вбок. Чтобы скорость
возвращалась сразу, как стрелки погасли, в `/var/opt/cluster-render/cluster-render.local.conf` стоит
`hud_linger_ms = 0` (по умолчанию 3000), после правки `systemctl restart cluster-render`. На X6 G06 так сделано 2026-11-07.

## После установки

Один раз перезапустить головное устройство и только потом трогать сервис командами `systemctl`.
recmgr читает список своих сервисов только при загрузке, а остановленный сервис, которого в этом списке нет,
перезагружает головное устройство.

## Выключить

`systemctl stop vr-hud-turn` (до следующей загрузки, только после перезапуска из раздела выше) или «Удалить» в Store.

## Проверка на машине

Каждый шаг выполняется только после «да» владельца.
Сделано 2026-11-07 пробными запусками из `/tmp`, без установки: Cluster renderer 0.4.1 уже стоял,
положение подобрано (`size` 40, `margin` 150, в 0.1.2 стало 190), такт замерен (640 мс, `StatusFunctionsIndicators2` в начале каждой вспышки).
0.1.x поставлена и проверена на ходу. Для 0.2.0 осталось:
1. Поставить 0.2.0 и приложение «Поворотники на HUD», перезапустить головное устройство.
2. Убедиться по журналу, что приходит режим (`FES.statusFESVehicleDynamicSwitchHMI`) и строки `place`.
3. В Sport подобрать в приложении высоту, при которой левая стрелка не задевает тахометр, и записать её в `y_sport` по умолчанию.
4. Проверить смену режима посреди поворота и поворот на ходу.

## Код

| Файл | Что делает |
|---|---|
| `main.js` | сборка сервиса, таймер, журнал |
| `signal.js` | значения поворотника от машины в `none` / `left` / `right` / `both` (или «ничего не значит») |
| `mode.js` | режим вождения в `sport` / `normal` |
| `appsettings.js` | сдвиги из приложения `vr_hud_turn` |
| `control.js` | сокет для приложения: `show`, `rec start` / `rec stop` / `rec status`, `share` |
| `recorder.js` | запись лога по кнопке |
| `share.js` | страница с логом на точке доступа машины |
| `blinker.js` | горит ли стрелка в этот момент (такт, привязка к началу вспышки) |
| `arrow.js` | треугольники стрелок и шейдер GLSL ES 1.00 (положение в uniform-ах `u_y`, `u_margin`, `u_size`, цвет в `u_r`, `u_g`, `u_b`) |
| `hud.js` | effect-слой на цели `hud` у cluster-render |
| `someip.js` | подписки SOME/IP через `/usr/lib/someip.node` |
| `oapgen.js` | описания интерфейсов штатным генератором MainApp |
| `config.js` | настройки, итоговое положение и цвет стрелок |

`someip.js` и `oapgen.js` сделаны по образцу кода idrive7-apps (MIT, `LICENSE.idrive7-apps`).
Тесты: `sh tests/run.sh` из корня репозитория.
