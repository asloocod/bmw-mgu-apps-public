# vr-warmup: прогрев двигателя на приборке

Пока мотор заведён и масло холоднее 80 °C, на приборке горит синий термометр над волнами. Масло прогрелось, значок гаснет.
Снова он загорается, только если масло остыло ниже 70 °C. Мотор заглушен (в том числе автостоп) или температуры масла
нет дольше 5 с: значок не горит.

Сервис без экрана в iDrive. Он стартует вместе с головным устройством (MGU, iDrive 7) и рисует через
[Cluster renderer](https://github.com/robertnisipeanu/idrive-apps/tree/main/native/cluster-render) (`cluster-render`),
цель `panel` (весь кластер 1920×720, над стрелками, под контрольными лампами). Машину сервис только читает:
подписки SOME/IP `CDS.statusEngineTemperature` и `VehicleInformation.DataPowerTrain2CRC`, ничего не пишет.

## Обязательно: своя сцена у panel

По умолчанию у cluster-render цели `panel` и `hud` делят одну сцену `0x01000400`, и вместе они не поднимаются.
Значок на `panel` держал бы её весь прогрев, и стрелки поворотников на HUD (vr-hud-turn) не появлялись бы.
Поэтому в конце `/var/opt/cluster-render/cluster-render.local.conf` должны стоять строки:

```
# vr-warmup (2026-11-07): panel's own scene, so the HUD (vr-hud-turn) and the panel can be up at once
panel_scene_id = 0x010004f2
scene_ids_allowed = 0x010004f0,0x01000400,0x010004f1,0x010004f2
```

Ключ в local.conf заменяет значение целиком, поэтому `scene_ids_allowed` перечисляет все четыре сцены.
После правки `systemctl restart cluster-render`, проверка: `cluster-render status` показывает
`target panel: slot 0x203 scene 0x10004f2`. Откат: удалить эти три строки и снова перезапустить cluster-render.

Без этой правки сервис работает, но значок не показывает никогда. В журнале одна строка:
`panel: its scene 0x1000400 is the hud's, the icon stays off so the HUD arrows keep working`.

## Настройки

Файл `/var/opt/vr-warmup/config.json` переживает обновления. Читается при старте, после правки нужен
`systemctl restart vr-warmup`. Неверное значение игнорируется, остаётся умолчание.

| Ключ | Умолчание | Диапазон | Что это |
|---|---|---|---|
| `warm_c` | 80 | 40–110 | масло, °C, с которого значок гаснет |
| `rearm_c` | 70 | 30–105 | ниже этого значок загорается снова (меньше `warm_c`, иначе `warm_c` − 10) |
| `stale_ms` | 5000 | 2000–60000 | столько мс без валидной температуры масла: значок гаснет |
| `x`, `y` | 1593, 473 | в пределах 1920×720 | левый верхний угол значка на панели, px (у тахометра, подобрано на X6 G06) |
| `size` | 56 | 24–240 | сторона значка, px |
| `color` | `[0.15, 0.5, 1.0]` | 0–1 | цвет RGB |
| `test_pattern` | `false` | | `true`: значок горит всё время, для подбора места |

Пример:
```json
{ "test_pattern": true, "x": 1580, "y": 540 }
```

## Журнал

```sh
journalctl -u vr-warmup -f
```
Те же строки пишутся в `/var/opt/vr-warmup/log/events.log` (256 КБ + `.1`): журнал головного устройства хранит
только минуты. Пишутся включение и выключение значка с причиной (`icon on (cold, oil 52 C)`), масло и ОЖ при
изменении, состояние мотора, флаг DME `reductionDownControlRPMDrive2` и `rPMEngineMaximumAllowed` (для будущего
предела оборотов, ×50 об/мин предположительно), сцена и состояния цели `panel`, ошибки запуска
(сервис сам повторяет запуск раз в 60 с, подписку раз в 30 с).

## После установки

Один раз перезапустить головное устройство и только потом трогать сервис командами `systemctl`.
recmgr читает список своих сервисов только при загрузке, а остановленный сервис, которого в этом списке нет,
перезагружает головное устройство.

## Выключить

`systemctl stop vr-warmup` (до следующей загрузки, только после перезапуска из раздела выше) или «Удалить» в Store.

## Проверка на машине

Каждый шаг выполняется только после «да» владельца.
Сделано 2026-11-07 на X6 G06: правка `cluster-render.local.conf` (копия `cluster-render.local.conf.bak-vr-warmup` рядом),
перезапуск cluster-render, пробный запуск из `/tmp` с `test_pattern`. KOMBI показал сцену `0x10004f2` в слоте 0x203
через ~270 мс, приборка не перезапускалась, стрелки HUD работали при горящем значке. Место подобрано по словам владельца.
Осталось:
1. Холодный старт: значок горит и гаснет на 80 °C, в журнале флаг DME и `rPMEngineMaximumAllowed`.
2. Поставить инструмент, перезапустить головное устройство.

## Код

| Файл | Что делает |
|---|---|
| `main.js` | сборка сервиса, таймер устаревания, журнал |
| `signal.js` | сырые значения в °C (raw − 48, 255 = нет данных) и состояние мотора |
| `warmup.js` | горит ли значок сейчас: порог, повторное включение, устаревшие данные |
| `icon.js` | термометр (формула фигуры) и шейдер GLSL ES 1.00 |
| `cluster.js` | effect-слой на цели `panel` у cluster-render, проверка своей сцены |
| `someip.js` | подписки SOME/IP через `/usr/lib/someip.node` (копия из vr-hud-turn) |
| `oapgen.js` | описания интерфейсов штатным генератором MainApp |
| `eventlog.js` | файл журнала (копия из vr-hud-turn) |
| `config.js` | настройки |

`someip.js` и `oapgen.js` сделаны по образцу кода idrive7-apps (MIT, `LICENSE.idrive7-apps`).
Тесты: `sh tests/run.sh` из корня репозитория.
