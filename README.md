# Приложения для BMW с головным устройством MGU (iDrive 7)

Инструменты и приложения для [mgu-store](https://github.com/robertnisipeanu/mgu-store). Ставятся и обновляются из Store.
Почти всё здесь машину только читает. Исключение одно: «Задний привод» по двойному нажатию отправляет одну команду
блоку VIP. Инструменты рисуют через
[Cluster renderer](https://github.com/robertnisipeanu/idrive-apps/tree/main/native/cluster-render).

| Инструмент | Что делает | Подробно |
|---|---|---|
| «Поворотники на HUD» (`vr-hud-turn`) | Стрелка поворотника на проекционном дисплее мигает в такт реле. При аварийке горят обе стрелки, при мигании от ассистента смены полосы горит стрелка его стороны. | [tools/vr-hud-turn](tools/vr-hud-turn/README.md) |
| Приложение «Поворотники на HUD» (`vr_hud_turn`) | Настройки стрелок в iDrive: выше или ниже, отдельно для Sport, шире или уже, размер, цвет и яркость. Там же запись лога и передача его на телефон. | [tools/vr-hud-turn](tools/vr-hud-turn/README.md#приложение-поворотники-на-hud) |
| «Прогрев двигателя» (`vr-warmup`) | Синий термометр на приборке, пока мотор заведён и масло холоднее 80 °C. Масло прогрелось, значок гаснет. | [tools/vr-warmup](tools/vr-warmup/README.md) |
| Приложение «Задний привод» (`vr_xdrive`) | По двойному нажатию отключает полный привод до выключения зажигания и показывает момент на передней оси. Только для VIP `0F2520` (X5 G05, X6 G06). | [apps/vr_xdrive](apps/vr_xdrive/README.md) |

## Что нужно

- BMW с головным устройством MGU (iDrive 7), root по SSH и установленный mgu-store.
- В Store добавлен источник `robertnisipeanu/idrive-apps`. Оттуда Store сам поставит Cluster renderer, без него оба инструмента не работают. «Заднему приводу» он не нужен.
- Интернет в машине на время установки: телефон по USB, USB-адаптер Ethernet, LTE-модем или Wi-Fi через mgu-uplink.

Проверено на BMW X6 G06 2021, прошивка P18_23w03.3-1-5. На другой машине положение стрелок, место значка и такт мигания
может понадобиться подстроить в `config.json` каждого инструмента, ключи описаны в их README.

## Как поставить

1. В Store: Add source, GitHub, `asloocod/bmw-mgu-apps-public`, канал `branch`.
2. Установите нужный инструмент.
3. Один раз перезапустите головное устройство. До перезапуска не останавливайте и не перезапускайте эти сервисы
   командами `systemctl`: recmgr читает список своих сервисов только при загрузке, и остановленный сервис не из
   этого списка перезагружает головное устройство.

Новые версии приходят в Store как обновления.

## Настройки Cluster renderer

Их правят по SSH в файле `/var/opt/cluster-render/cluster-render.local.conf`, затем выполняют
`systemctl restart cluster-render`.

Строка `hud_linger_ms = 0` для стрелок на HUD. Пока на HUD что-то показано, приборка сдвигает скорость вбок.
С этой строкой скорость возвращается сразу, как погасли стрелки. Без неё через 3 секунды.

Для прогрева обязательны две строки, иначе значок не появится:

```
panel_scene_id = 0x010004f2
scene_ids_allowed = 0x010004f0,0x01000400,0x010004f1,0x010004f2
```

Почему так, написано в [tools/vr-warmup/README.md](tools/vr-warmup/README.md).

## Если что-то пошло не так

Для стрелок на HUD лог проще всего снять приложением «Поворотники на HUD»: «Начать запись лога», поездка,
«Остановить запись лога», затем «Отдать лог на телефон» и файл в Telegram. Подробно в
[tools/vr-hud-turn/README.md](tools/vr-hud-turn/README.md#лог-для-разбора).

Удалить инструмент можно в Store. Журнал сервиса: `journalctl -u vr-hud-turn` или `journalctl -u vr-warmup`,
те же строки сохраняются в `/var/opt/<инструмент>/log/events.log`.

Это любительские инструменты, их ставят на свою ответственность.
